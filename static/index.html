구글 스프레드시트 연동 설정 (관리자 전용)

본 설정은 '관리자' 권한을 보유한 사용자만 수정할 수 있습니다. Google Apps Script Webhook URL을 설정하여 실시간 시트 및 드라이브 폴더 쓰기 연동을 구성하세요.

연동 절차 안내:
  1. 구글 시트 상단 메뉴 [확장 프로그램] → [Apps Script] 클릭
  2. 프로젝트 루트의 google_apps_script.js 코드를 복사하여 붙여넣기
  3. 우측 상단 [배포] → [새 배포] → 유형: [웹 앱] (액세스 권한: 모든 사용자) 배포 후 URL 입력
